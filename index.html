Proof of work

Four tools, all open source, with public demos. Their demos run on synthetic, bundled or public sample data — no client or production data.

PipelineProbe

One command, one HTML report: audit Airflow, dbt and warehouse health before a migration or after an incident.

What it proves An installable CLI on PyPI, a deterministic Docker quickstart, and a live sample report.

Live demo Source pip install pipelineprobe==0.3.1

ObservaKit

Self-hosted data observability and FinOps starter kit: freshness, volume and schema checks, plus cloud cost tracking.

What it proves A self-hosted Docker Compose stack — Postgres, Prometheus and Grafana — that audits Airflow and dbt pipelines, with zero vendor lock-in.

Live demo Source

plm-bom-pipeline

A synthetic bicycle manufacturer's PLM data — parts, five-level BOMs and ECR/ECO/ECN change control — modelled into seven tested dbt marts on DuckDB.

What it proves PLM domain modelling with 195 checks, a seven-defect attribution harness, a static report and a narrated walkthrough.

Live demo Source make demo

rag-docs-chatbot

Ask questions of a document set and get answers that cite the exact page — or an explicit "I don't know". Runs over two public NIST digital-identity standards.

What it proves Retrieval you can check: FastAPI, Postgres + pgvector, hybrid search and reranking, a 40-question evaluation (87.5% evidence hit@5), and a public demo on a free open model with a fair per-visitor limit.

Live demo Walkthrough Source docker compose up
